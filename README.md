# Lunar Asset Management Website Demo

This repository contains only the generated static demo site for boss/client review.

Primary rule for all Lunar Asset Management sites: this demo is updated first. After approval or any copy/design change, the live site must be updated from the demo and verified so both public URLs show the same site.

Live site after GitHub Pages publishes:

https://jmlawton74.github.io/Lunar_Asset_Management-Demo/

Direct Imperial Manor preview:

https://jmlawton74.github.io/Lunar_Asset_Management-Demo/imperial-manor/

The working source repository can stay private. To update this demo, rebuild the source project, copy the contents of `Website Portfolio/dist` into this repository, commit, and push. Then sync the corresponding live property repo and run the shared parity check from `Website Portfolio`.
